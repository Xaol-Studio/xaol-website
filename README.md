# XAOL Studio | Sitio Web Oficial & Demos

Sitio web corporativo y de captación de clientes para **XAOL Software Studio**, agencia independiente de software a medida y páginas web de alta conversión para PyMEs.

## 🚀 Características
- **Landing Page de Alta Conversión:** Diseñada con Tailwind CSS, modo oscuro moderno y microinteracciones de alto impacto.
- **Cotizador Rápido Interactivo:** Calcula presupuestos estimados en tiempo real y enlaza directamente con el WhatsApp oficial de la agencia (+52 593 126 9253).
- **Demos Interactivas en Vivo:**
  - `demo/pyme-manager.html`: Sistema de gestión de inventarios, punto de venta y arquitectura SQL relacional.
  - `demo/citas-servicios.html`: Portal de captación y confirmación de citas médicas y dentales.
- **Despliegue Instantáneo:** Compatible con Vercel, Cloudflare Pages o GitHub Pages sin dependencias de servidor complejas.

## 🛠️ Stack Tecnológico
- HTML5 Semántico
- Tailwind CSS (CDN optimizado)
- Vanilla JavaScript moderno
- Vercel Edge Network
