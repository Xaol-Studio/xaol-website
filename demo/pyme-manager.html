Tecnología Central

Arquitectura de Base de Datos Relacional

Por qué en XAOL construimos sobre bases de datos SQL en lugar de hojas de cálculo.

Esquema de Tablas (DDL) Normalizado (3NF) 

CREATE TABLE productos (
  id SERIAL PRIMARY KEY,
  sku VARCHAR(50) UNIQUE NOT NULL,
  nombre VARCHAR(255) NOT NULL,
  categoria_id INT REFERENCES categorias(id),
  precio_unitario NUMERIC(10,2) NOT NULL,
  stock_actual INT NOT NULL DEFAULT 0,
  stock_minimo INT NOT NULL DEFAULT 5
);

CREATE TABLE ventas (
  id SERIAL PRIMARY KEY,
  cliente VARCHAR(255) NOT NULL,
  total NUMERIC(10,2) NOT NULL,
  metodo_pago VARCHAR(50) NOT NULL,
  creado_el TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Integridad Transaccional (ACID)

Si dos vendedores venden el último producto al mismo tiempo, una hoja de Excel se rompe o genera duplicados. En nuestro software, una transacción SQL bloquea el registro en microsegundos y previene ventas sin existencias.

Seguridad & Auditoría

Cada cambio, ajuste de precio o anulación de factura queda registrado con fecha, hora y usuario. Nadie puede "borrar una celda" sin dejar rastro.

Escalabilidad Ilimitada

Soporta más de 1,000,000 de registros y 100 usuarios concurrentes sin degradar la velocidad ni ralentizar las operaciones diarias.
